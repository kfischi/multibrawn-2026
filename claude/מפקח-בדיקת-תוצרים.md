# מפקח בדיקת תוצרים — MULTIBRAWN

> כל תוצר (מאמר, עמוד, עיצוב, פוסט) חייב לעבור את כל הסעיפים לפני שעולה לאוויר.
> עודכן: 9.11.2026

---

## 1. שפה ואיכות כתיבה
- [ ] אין שגיאות כתיב — נקרא מילה-מילה
- [ ] השם תמיד **ערדית** (בע') — לעולם לא "ארדית"
- [ ] שורות קצרות — כל שורה עומדת בפני עצמה
- [ ] אין משפטים ארוכים ומחוברים
- [ ] רמה גבוהה — לא עברית מתורגמת, לא קלישאות
- [ ] גוף ראשון ("אני") במאמרים ובדפים אישיים של ערדית

## 2. זהות המותג
- [ ] ערדית **מחברת** — לא מוכרת נכסים ולא מנהלת קטלוג
- [ ] מילת העוגן **התאמה** נוכחת
- [ ] מילות המותג: התאמה · דיוק · מהשטח · עקביות · רצינות · ראש שקט · חיבור
- [ ] אסור: המילה **"סוכנות"** על MULTIBRAWN
- [ ] אסור: אזכור "מקומות לאירועים" / "צימר ישראל"
- [ ] אסור: ערבוב מותגים (MULTIBRAWN ≠ Multi UGC ≠ Easylanding)

## 3. עיצוב
- [ ] פלטה: **שחור · לבן פנינה · סגול בוהק · פוקסיה חי** בלבד
- [ ] **לעולם לא צהוב. לעולם לא זהב.**
- [ ] נבדק במובייל 390px לפני מסירה
- [ ] תמונות/סרטונים — רק חומר מאושר של ערדית

## 4. אמת בפרסום — קו אדום
- [ ] אין המלצות, מספרים, מחירים או סיפורי הצלחה **מומצאים**
- [ ] נתונים מאושרים בלבד: "11,200+ חברים", "דמי רצינות 50 ₪"
- [ ] סכומים ומחירים — רק אם ערדית אישרה במפורש

## 5. טכני (קוד ועמודים)
- [ ] `tsc --noEmit` — נקי על הקבצים ששונו
- [ ] מטא מלא: title, description, canonical, OG
- [ ] הוספה ל-sitemap ולרשימת הבלוג
- [ ] קישורים פנימיים רלוונטיים
- [ ] אין כפילות "| MULTIBRAWN" בכותרות

## 6. תוכן שבת חתן (לכל מאמר/עמוד בנושא)
- [ ] מלונות מעדיפים 15–25 חדרים, לא אוהבים שבתות חתן
- [ ] הבחנה חרדי / דתי / מעורב
- [ ] כשרות: רבנות / מהדרין / בד"ץ
- [ ] שאלון — תנאי להתאמה (ללא שאלון אין המלצה)
- [ ] שני המדריכים: חינמי (free-guide.multibrawn.co.il) + מלא (guide.multibrawn.co.il)

## 7. לפני מיזוג לאתר החי
- [ ] אישור מפורש של **ערדית**
- [ ] PR עבר CI ירוק (Netlify + Vercel)
- [ ] נצפה בדפדפן ובמובייל בפועל
